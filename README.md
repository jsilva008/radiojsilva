# JSILVAfm — Site cinematográfico
Abra index.html no navegador ou publique estes arquivos em hospedagem HTTPS, como GitHub Pages, Netlify ou Cloudflare Pages.

A seção Experiência altera o currentTime do vídeo conforme a rolagem. O clipe atual é demonstrativo e remoto; substitua seu source no index.html por media/filme.mp4 para usar um vídeo próprio (MP4/H.264 otimizado).

Para ativar a rádio ao vivo, configure STREAM_URL no início de script.js com o endereço completo do streaming.

Arquivos: index.html (estrutura), style.css (design responsivo) e script.js (sincronização do vídeo, player e menu móvel).
